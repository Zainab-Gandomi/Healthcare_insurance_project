# Healthcare Insurance Cost Analysis

## Project Overview
This project analyses healthcare insurance charges to understand how costs vary across different personal characteristics and geographical regions.

The aim is to identify patterns in insurance charges and provide useful insights to support healthcare insurance planning and decision-making.

## Business Problem
Healthcare insurance organisations need to understand which factors are associated with differences in insurance charges. This project explores how age, BMI, smoking status, number of children and region relate to insurance costs.

## Project Objectives
- Analyse differences in insurance charges between customer groups.
- Explore relationships between personal characteristics and insurance charges.
- Compare insurance charges across geographical regions.
- Create visualisations to communicate findings.
- Explore how data analytics and AI could support future cost estimation.

## Dataset
The project uses the Healthcare Insurance dataset from Kaggle.

- Number of records: 1,338
- Number of columns: 7
- Missing values: None found during initial inspection.
- Duplicate rows: 1 exact duplicate identified for further investigation.
